## 📖 Descripción del Repositorio

En este repositorio se documenta el progreso práctico de la materia, incluyendo implementaciones en **Python** de:
* Algoritmos de ordenamiento y búsqueda.
* Estructuras de datos lineales (Listas, Pilas, Colas).
* Estructuras de datos jerárquicas (Árboles BST, AVL).
* Análisis de complejidad algorítmica.
